# ATMA Model V5

ATMA (Adaptive Technology for Motorized Applications) shown end to end on one vehicle, the Trike N (L1, Bengaluru), for two customers: from the customer's words to the requirement, environment, routes, drive cycle, sizing, parts, spec sheet, powertrain simulation and the bill of materials.

Open `index.html` in a browser (Chrome, Edge or Firefox). Keep the `img` folder next to it.
With GitHub Pages turned on for this folder, the page opens at the Pages address.

- Click a block to follow its data; double-click to go inside; `/` or Ctrl K to search.
- Right-hand buttons: model map, details, guided tour, bill of materials. Every window can be dragged and resized.
- The moon button switches dark mode.
